# Security boundaries

GigVault is a locally tested hackathon prototype, not a production financial or identity service.

Evidence attestation requires authenticated Mock FIP provenance, valid consent, owner binding and curated payout originators. The trusted prover independently checks the current passport and signed policy/worker approval before accessing private reconstruction. Consumer contracts repeat math, current evidence, exact policy, approval and replay/business-state checks.

Private evidence and witnesses are transient. Proof responses exclude financial arrays. The server owns private IPC and A loopback capabilities; it does not provide an unauthenticated public proving service.

The sample OTP `123456` and `DEMO-AADHAAR-0001` are UI fixtures. Their completion flags do not constitute genuine phone/Aadhaar authentication; actual backend wallet authentication remains separate. Mock IDP must never be represented as a genuine real-verifier result. Local unlocked wallets and development proving keys are unsuitable for public deployment.

Do not submit real identity, banking or credential data in issues, screenshots or test fixtures. Report vulnerabilities through GitHub's private vulnerability reporting if enabled, or contact a repository maintainer privately. Do not publish sensitive exploit data in an issue. No external audit or production security certification is claimed.
